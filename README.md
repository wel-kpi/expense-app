# 経費精算メモ

領収書写真を添えて経費を記録し、月末に指定フォーマットのExcel（経費精算書）を出力するブラウザアプリです。データはブラウザのIndexedDBにのみ保存され、外部サーバーへは送信されません。

## 機能
- 経費登録フォーム（支払日・支払先・登録番号・内容・利用目的・支払額・同席人数・領収書画像）
- 領収書画像からのOCR自動読み取り（Tesseract.js、あくまで補助）
- 月ごとの経費一覧・編集・削除
- カテゴリ別の当月サマリーと前月比
- 月次Excel出力（経費精算書シート＋領収書貼付シート）

## ローカルで動かす
`index.html` を任意の静的サーバーで配信してブラウザで開くだけで動作します（ビルド不要）。

## 公開
`main` ブランチへのpushで GitHub Actions が自動的に GitHub Pages へデプロイします。
